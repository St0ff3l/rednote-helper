# xhs-media-helper V4

参考 [空什么格的小红书下载器](https://www.icloud.com/shortcuts/48c45bf28b50473f82c818d5977d1a14) 的解析服务和保存动作，增加预览、多选及明确失败提示。

## 使用

1. 在 iPhone 安装并打开一次 [实况捷径 App](https://apps.apple.com/cn/app/id6744431514)。图片与 Live 分支都需要它；不需要 Actions App。
2. 导入 `xhs-media-helper-v4.shortcut`。
3. 复制小红书分享文字后运行，或从分享表单运行。
4. 初始菜单选择 Live 实况图、图片或视频。
5. 选择要保存的项目（可多选），完成预览后关闭预览继续保存。Live 用封面预览选择。
6. 按提示允许联网及照片权限，然后到照片 App 检查。Live 应显示 LIVE，长按应播放。

## 参考逻辑与改动

- Live：沿用 EncryptExtension 与 livexhs 解析；将对应的 pic/video 地址交给实况捷径 LiveExtension，保留独立封面输入。不是把两个文件分别保存。
- 图片：沿用 xhshd 解析；下载预览、多选后，将所选原地址交给 ResourceExtractionExtension 直接保存。不能把它的空返回值交给系统相册。
- 视频：沿用参考指令高清路径的远程 Cookie、网页 HTML 文件提交、服务指定文件名，再将所选下载文件传入系统“保存到相册”。服务暂停高清路径时提示停止；参考原版还提供普通视频等额外菜单，此版只保留上述三个入口。
- 使用参考作者的服务配置，授权码默认留空；已有授权码可在开头文本填写。笔记链接及网页内容将发送至作者解析服务。
- 数字判断显式转换成数字，防止保存类型被按文本判断而进入错误分支。
