# V4.1 动图工厂保存版

在 V4 基础上优化文件处理，参考 [小红书助手pro v4.7](https://www.icloud.com/shortcuts/65fbd12188ff492e9be1ac577bd9983f) 的动图工厂文件动作。原 V4 文件保留，便于回退。

## 变化

- 初始 Live / 图片 / 视频菜单、原 V4 解析服务、预览与多选保持原有流程。
- Live 下载独立封面和配对动态视频，将封面 PNG 文件与 MP4 文件传给动图工厂 `SaveLivePhotoFromFilesIntent` 保存。
- 图片显式转换为 PNG 文件，再将所选图片交给系统相册。不再通过实况捷径的资源提取动作保存。
- PNG 转换没有主动缩放，也不增加 JPEG 有损压缩，但会改变文件编码与元数据；不能称为原始文件字节无损。
- 新卖家的 Tencent CloudBase 解析服务、激活码校验和设备绑定均未接入。动图工厂动作只有 imageFile / videoFile 参数，没有激活码参数；App 内部行为尚未在 iPhone 验证。

## 使用与依赖

1. 安装 [动图工厂](https://apps.apple.com/us/app/id6762482512)，App Store 标为免费，最低 iOS 17。
2. Live **解析**仍需要实况捷径生成原 V4 服务所需 payload，因此当前 Live 路线需要两个 App。图片和视频的保存使用系统动作。
3. 导入 `xhs-media-helper-v4.1.shortcut`，复制笔记链接后运行。选项目、关闭预览，允许照片权限，然后在照片 App 检查。
4. 不要把新卖家的激活码填入 V4 或 V4.1 的授权码栏：服务不同，未验证兼容性。原有参考服务额度限制仍适用。

## 验证范围

三路本地夹具测试验证数字分支、选择第二张 Live 后的对应视频地址、独立封面文件及视频文件类型、图片 PNG 解码和传入系统保存动作的图像。测试替换网络、App、用户交互和相册，不代表 iPhone 实际保存成功。未在 Mac 安装或运行动图工厂。

真实解析链路、相册保存、App 是否存在运行时限制、源素材是否无水印，以及最终 Live 的尺寸和编码仍需 iPhone 测试。此前网页动态源已发现右下角平台水印；合成不能消除源中水印。
