# V4.5 本地解析版

- 快捷指令名称：小红书素材助手 V4.5。
- Live 和普通视频不调用 Pro 作者的云端解析接口，也不调用 qsy 解析服务。快捷指令直接获取小红书移动网页，在 iPhone 本地解析笔记状态中的 Live 封面 ID、配对视频 CDN 地址，或普通视频 CDN 地址。
- Live 封面与配对视频下载到本机后交给动图工厂生成并保存；动图工厂不是解析服务客户端。
- 图片继续在本地解析网页状态中的原图 ID；三类素材实际下载仍需联网访问小红书页面和 CDN。
- 成功数量通知、emoji 菜单、详细分支错误提示沿用 V4.4。没有第三方授权码输入框。

解析路径基于用户提供的 Live 和视频笔记移动网页状态字段；签名/格式/权限差异可能导致其他笔记解析失败。小红书返回的动态资源是否带水印、Live 封面分辨率和正确配对仍需 iPhone 验证。本版未在 Mac 运行动图工厂，也尚未进行 iPhone 端到端测试。
