# V4.4 保存结果提示

快捷指令中文名为「小红书素材助手 V4.4」。初始菜单为「📸 Live 实况图」「🖼️ 图片」「🎬 视频」，多选提示同步增加 emoji。保留 V4.3 的解析、原图下载、多选和保存方式；用户已反馈 V4.3 可以保存。

- 图片、视频保存动作完成后显示「🎉 保存成功」，正文为「✅ 已保存 X 张图片／X 个视频到相册」。
- Live 全部所选项目完成动图工厂保存动作后，统一显示「✅ 已保存 X 张实况照片到相册」。开启通知声音，不增加编辑或确认界面。
- 各分支增加 emoji 和具体错误说明，覆盖分享链接缺失、图片数据缺失、原图标识异常、视频服务未开放、第三方解析失败、Live 配对不完整、下载结果为空及未选择素材；失败时停止，不继续显示成功通知。
- 保留第三方服务返回的错误原因；系统网络、转换、相册权限或 App 自身抛出的错误仍由快捷指令显示原生错误。快捷指令没有通用的 try/catch，本版不会假称可以包装所有系统错误。
- 通知在保存动作正常返回后显示，遵循参考助手的做法。动图工厂若静默失败，本指令无法独立核验其写入相册结果。Live 中途失败时，之前完成的项目可能已经保存。

本地夹具验证图片、视频、Live 的选择映射、数量和保存后通知顺序，并确认第三方返回失败时不会执行保存或发送成功通知；测试替换 App、相册和通知动作，没有在 Mac 实际保存或发送通知。V4.4 新增提示尚待 iPhone 验证。
