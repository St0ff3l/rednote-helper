# V4.6 本地解析修复版

- 快捷指令名称：小红书素材助手 V4.6。
- 修复 Live 配对列表与响应 JSON：先把封面/视频配对物化为文本并追加到列表，再对嵌入响应字符串的引号和换行符做 JSON 转义，确保 `code` 和 `body.lives` 可被快捷指令正常读取。
- Live 和普通视频仍在快捷指令内读取小红书移动网页状态，不调用 Pro 作者或 qsy 的云端解析服务；Live 下载封面及对应视频后交给动图工厂保存。
- 初始菜单、预览/手动多选、成功数量通知及带 emoji 的详细分支错误提示沿用 V4.5；选择列表默认不勾选全部项目。静态图片流程继续本地读取原图 ID。

## 样例验证

分别读取了两条公开 Live 笔记的移动网页数据：

- “10张爆款极品live图”：10 张均带 `livePhoto` 标记、原图 ID 和配对视频地址。
- “高质量极品小说黑白车流live实况素材图”：9 张均带上述字段。

在 macOS 快捷指令运行环境中，以这两份网页响应执行 Live 解析分支，确认响应 JSON 字典中的 `code` 可读取，且 `body.lives` 中的 10 组和 9 组配对都能逐项解析。该验证覆盖本地解析及配对逻辑，没有执行动图工厂或写入照片图库，也不等同于 iPhone 端到端成功。

动态视频源是否带水印、封面分辨率，以及动图工厂在 iPhone 上的保存行为仍需手机实测。签名或导入也不能替代此验证。

## 在 iPhone 验证

1. 安装并打开一次[动图工厂](https://apps.apple.com/us/app/id6762482512)。
2. 更新现有的“小红书素材助手 V4.6”快捷指令；不要添加第二份同名副本。快捷指令会通过 iCloud 同步到已登录同一 Apple 账户的设备。
3. 在小红书复制包含 Live 图的笔记分享内容后运行，选择“📸 Live 实况图”，勾选项目并确认。
4. 到照片 App 检查保存数量、LIVE 标记、长按播放，以及封面尺寸和水印情况。
